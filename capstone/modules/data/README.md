# Data Module

Creates a private MySQL RDS instance with encrypted storage, a dedicated subnet group, and an RDS-managed master password in Secrets Manager.

## Inputs

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `project_name` | `string` | required | Prefix for names and tags |
| `private_subnet_ids` | `list(string)` | required | At least two private subnets |
| `db_security_group_id` | `string` | required | Security group that allows MySQL from the app tier |
| `db_name` | `string` | `appdb` | Initial database name |
| `username` | `string` | `appadmin` | Master username |
| `instance_class` | `string` | `db.t3.micro` | RDS instance class |
| `engine_version` | `string` | `8.0` | MySQL engine version |
| `allocated_storage` | `number` | `20` | Initial storage in GiB |
| `max_allocated_storage` | `number` | `100` | Storage autoscaling ceiling |
| `multi_az` | `bool` | `false` | Enable a Multi-AZ standby |
| `backup_retention_period` | `number` | `7` | Automated backup retention in days |
| `deletion_protection` | `bool` | `false` | Block deletion |
| `skip_final_snapshot` | `bool` | `true` | Skip the final snapshot on destroy |
| `final_snapshot_identifier` | `string` | `null` | Snapshot name when `skip_final_snapshot` is false |
| `apply_immediately` | `bool` | `false` | Apply changes during the maintenance window |
| `tags` | `map(string)` | `{}` | Extra tags |

## Outputs

| Name | Description |
|------|-------------|
| `db_instance_id` | RDS instance identifier |
| `db_address` | Hostname of the database |
| `db_endpoint` | Hostname and port |
| `db_port` | Database port |
| `db_name` | Initial database name |
| `db_subnet_group_name` | Subnet group name |
| `master_user_secret_arn` | Secrets Manager ARN (sensitive) |

## Retrieving the password

The password is generated by RDS and stored in Secrets Manager. Terraform never sees it.

```bash
aws secretsmanager get-secret-value \
  --secret-id "$(terraform output -raw master_user_secret_arn)" \
  --query SecretString --output text
```

## Production notes

- Set `multi_az = true`, `deletion_protection = true`, and `skip_final_snapshot = false`.
- Enable performance insights and enhanced monitoring for real workloads.
- Use a customer-managed KMS key if your compliance regime requires it.
