# Module 1: Foundations

**Duration:** ~4-6 hours | **Level:** Beginner | **Prerequisites:** None

## Module Overview

This module lays the groundwork for your Terraform journey. You'll learn what Infrastructure as Code is, why Terraform exists, how to set up your environment, and run your first Terraform commands.

## Learning Objectives

By the end of this module, you will be able to:

- Explain Infrastructure as Code (IaC) and its benefits
- Describe what Terraform is and when to use it
- Set up Terraform and AWS CLI on your local machine
- Configure AWS credentials securely
- Write basic Terraform configurations using HCL
- Understand and use the core Terraform workflow (init, plan, apply, destroy)

## Module Summary

After completing this module, you'll have a working Terraform environment and understand the fundamentals needed to build more complex infrastructure.
